<p align="center">Native Discord client for macOS built in Swift</p>

**SwiftyCord** is a modern Discord client based on Swiftcord, redesigned with an improved architecture and extended functionality.

## Features

- Direct messages support
- Full Discord server support
- Built-in Socks5 proxy module
- Fast and native performance powered by Swift
- Discord Presence
- Modular architecture built with:
  - DiscordKit
  - Socks5Proxy
  - swift-opus
  - SwiftyGif
  - DiscordPresenceKit
  - Sparkle

- **DiscordPresenceKit**
- **Socks5-Proxy**
- **SwiftyGit**

## Installation

1. Download the `.dmg`
2. Drag Swiftcord into your Applications folder
3. Launch the app (see note above regarding Gatekeeper)
